# Swift Tunes Player 

Swift Tunes Player is a simple console-based music player built using Java.  
The project allows users to control audio playback through simple commands
like play, stop, reset, forward, and backward.

I created this project to practice Java programming, working with audio files,
and understanding how basic media player functionality works.

## Features

- Play audio files
- Stop and resume playback
- Reset the song
- Move forward and backward in the audio
- Simple command-line controls

## Used

- Java
- Java Sound API
- Object-Oriented Programming concepts

- ## Controls

P - Play  
S - Stop  
R - Reset  
F - Forward  
B - Backward  
Q - Quit  

## Future Improvements

I plan to improve this project by adding a graphical user interface,
playlist support,better audio controls, and support for more audio formats.
